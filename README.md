Webová aplikace pro nastavení různých časovačů. Aplikaci jsem dělal s pomocí Gemini, ale nekopíroval jsem kód, nechával jsem si radit jak postupovat. HTML a CSS je můj kód, nějaké řádky JavaScriptu jsou kód od Gemini. Celkem mi trvalo cca 5 hodin aplikaci vytvořit.

Ukládání funguje na bázi Local Storage.
